## 🛠️ Learning Method

Each lesson contains:

- `lesson.py` — working examples and explanations
- `practice.py` — exercises to solve independently
- `README.md` — concise lesson notes

The progression is:

**learn → visualize → practice → analyze → build**

## 🎯 Goal

The goal is not to memorize every Matplotlib function.

It is to learn how to choose and create visualizations that **help understand data and communicate insights clearly.**
